# AppGallery 4.1 remediation — candidate 1.3.0
The original 1.2.1 game remains available as Classic. A native puzzle hub adds two distinct rule systems: Garden Routes (matching via an unobstructed orthogonal path with at most two bends, with a generated solution), and Memory Grove (hidden pairs and delayed mismatches), selectable difficulties, deterministic daily challenges and local completion counts. No money, music, extra permissions, network service or new ad-choice screen is introduced. English (UK), Arabic with RTL, and Brazilian Portuguese are provided for the new screens. Classic retains its original settings; hub language is independent pending integration with the existing DataStore.

The original ZIP is retained. The expansion is applied after the existing 1.2.1 patch and fails closed if the manifest launcher or expected version markers differ. Package name and production key are not changed. Existing production build workflow is intentionally not modified until the debug candidate passes and production signing is confirmed. New modes currently contain no ad placements; original ads remain subject to existing consent gate.

Validation workflow compiles the pure Java engine, checks generated solutions and deterministic memory pairs, then compiles the original + expansion Android debug build. It does not sign or publish a production APK. Physical device, RTL, UI, actual ads, privacy policy consistency, original progress and store approval remain unverified. Release gate: inspect sources after unpacking, run on API 26 and 29 / Huawei devices, verify original signing certificate and ad IDs, verify version 5, update screenshots and descriptions from actual build, and never submit debug APK.
