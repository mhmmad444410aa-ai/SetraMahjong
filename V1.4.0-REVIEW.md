# Setra Mahjong v1.4.0 — Puzzle Atelier

Version: 1.4.0 (versionCode 7) · Package: `com.mhmmad.setramahjong`

## User-visible changes
- Original premium Jetpack Compose **Classic Mahjong** remains the primary Android launcher and playable campaign, with 120 original campaign stages.
- Prominent illustrated **Puzzle Atelier** entry on the ORIGINAL home screen (not an invisible second Android launcher).
- Three playable modes accessible through that entry:
  - **Garden Routes**: matching tile routing through up to two bends, scalable boards.
  - **Memory Grove**: hidden pairs with a timed flip-back, multi-stage boards.
  - **Daily Seed**: repeatable per-day deterministic offline deal.
- Original classic mode now displays a localized animated **match streak** when two or more legal matches occur within 12 seconds.
- Floating home emblem (respects Reduce Motion) and multilingual mode titles.
- UI languages: English default, Arabic (RTL), and Portuguese (Brazil).
- Existing advertising IDs, privacy compliance gates, original package, and original store-facing metadata are preserved.

## Build and verification
The source archive is `SetraMahjong_120_Project.zip` in repository root; original Kotlin extracted for controlled editing under `source-v14`.

Build patch sequence: `tools/patch-release-121.py`, `tools/patch-release-130.py`, `tools/patch-release-131.py`, `tools/patch-release-140.py`. The final patch restores **MainActivity** as the sole launcher in both main and Huawei Petal manifests.

The CI workflow `validate-setra-140.yml` checks generated route/memory deals, original engine unit tests, three-language resources, ad integration, debug assembly, strict production lint (with a *throwaway* testing key), and verifies the actual packaged MainActivity. Debug APK is explicitly for **TEST ONLY**.

The signed production-candidate workflow `secure-release-140.yml` transfers the authorized publisher signing key only through ephemeral encrypted CMS, builds `assembleRelease`, verifies package/version/certificate/launcher and uploads an artifact. Private signing files and passwords MUST NEVER enter this public repository.

**Do not submit to AppGallery until the signed APK is manually installed and checked on an Android 23+ device** for the new hub, Classic Mahjong, daily/memory/routes play, ad privacy behavior, English/Arabic/Portuguese display, rotation/back behavior, and crash-free sessions. Passing CI cannot guarantee Huawei AppGallery acceptance.
